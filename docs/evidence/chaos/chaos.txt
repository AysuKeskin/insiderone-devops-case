Chaos check: delete the running pod and watch Kubernetes rebuild it.
Dev values run a single replica, so this is a visible restart; values-prod
runs three behind a RollingUpdate, where the same event is invisible.

--- 1. before ---
$ kubectl get pods -l app.kubernetes.io/name=kube-pulse
NAME                          READY   STATUS    RESTARTS   AGE
kube-pulse-665645549c-ql2bz   1/1     Running   0          28s

--- 2. kill it ---
$ kubectl delete pod kube-pulse-665645549c-ql2bz
pod "kube-pulse-665645549c-ql2bz" deleted from default namespace

--- 3. the ReplicaSet immediately schedules a replacement ---
$ kubectl get pods -l app.kubernetes.io/name=kube-pulse
NAME                          READY   STATUS    RESTARTS   AGE
kube-pulse-665645549c-fc2wm   0/1     Running   0          1s

--- 4. back to Ready in 3s, serving again ---
$ kubectl get pods -l app.kubernetes.io/name=kube-pulse
NAME                          READY   STATUS    RESTARTS   AGE
kube-pulse-665645549c-fc2wm   1/1     Running   0          5s
$ curl -s localhost:8090/ping
pong
$ curl -s localhost:8090/version
